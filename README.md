# Seguretat-PAC01
# Anàlisi d'un conjunt de dades - Pokémon
 
Projecte de l'assignatura **0378 - Seguretat i alta disponibilitat** (Tema 1: Alta disponibilitat).
 
## Descripció
 
Aquest projecte consisteix en l'anàlisi exploratòria d'un conjunt de dades de Pokémon, incloent la seva neteja, visualització i l'estudi de diverses preguntes de recerca sobre les seves estadístiques (HP, Attack, Defense, Speed...), tipus i generacions.
 
## Estructura del repositori
 
```
├── PokemonData.csv        # Dataset original
├── analisi_pokemon.ipynb  # Notebook amb l'anàlisi (Jupyter)
└── README.md              # Aquest fitxer
```
 
## Tecnologies utilitzades
 
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
